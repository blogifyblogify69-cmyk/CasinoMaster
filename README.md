# CasinoMaster

Android observe-only prototype for monitoring a visible game screen.

## Current scope
- Android settings UI
- Configurable display-only amount and multiplier
- Accessibility-service based visible-text monitoring
- Start by enabling the service in Android Accessibility Settings
- Detection status is reported through the app/service

## Safety scope
This prototype does **not** automatically place bets, press cash-out, or execute real-money wagering actions.

## Build
Open the project in Android Studio and build the debug APK.

The GitHub Actions workflow also builds the debug APK and uploads it as a workflow artifact.
