# CasinoMaster

Minimal Android application shell.

All runtime monitor, automation, screen-inspection, floating-control, betting/collect, profile, and app-selection UI has been removed from the active application flow.

The current launcher opens a single basic screen. Existing legacy source files may remain in the repository history/source tree, but they are no longer registered or invoked by the Android application.

Build the debug APK with Android Studio or GitHub Actions.
